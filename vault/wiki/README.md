# vault/wiki

Distilled, graph-linked knowledge notes — one concept, project, or artifact
per file, connected with `[[wikilinks]]`. This is the long-term memory graph
JARVIS OS agents read from and write to, distinct from Mark-L's
`memory/long_term.json` (which stays small and is loaded into every Gemini
Live session prompt).

Conventions:

- One topic per file, named after the topic (`oauth2.md`, `redis-clone.md`).
- Link related notes with `[[other-note-name]]` rather than duplicating
  content across files.
- `resume.md` is the canonical master resume other agents (scout, brand,
  radar) read from — keep exactly one copy of it here.

See `specs/JARVIS_OS.md` §6.
